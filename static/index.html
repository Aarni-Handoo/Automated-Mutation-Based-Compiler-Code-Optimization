Supported language & integer contract

One Python function with positional built-in integer inputs, local assignments, +, −, *, parentheses and a final integer return. TAC accepts one operation per assignment. No calls, imports, loops, branches, floats or custom objects. Annotations do not enforce types in exported Python. Parsing never executes submitted code.
